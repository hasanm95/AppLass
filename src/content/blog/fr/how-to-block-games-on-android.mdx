**Il existe trois bonnes façons de bloquer les jeux sur Android.** La minuterie de Bien-être numérique
plafonne chaque jeu par jour. Google Family Link permet aux parents de gérer le téléphone d'un enfant. Et un
bloqueur d'applications bloque tous les jeux selon un planning hebdomadaire ou pendant une session de
concentration, sans bouton de contournement tant que le blocage dure.

## Pourquoi les jeux sont plus difficiles à lâcher que les autres applications

Les jeux mobiles sont conçus pour vous faire revenir : récompenses quotidiennes, énergie qui se recharge,
séries, événements qui se terminent bientôt. « Une petite partie » pendant une pause de révision devient
vite quarante minutes. Désinstaller fonctionne jusqu'à la prochaine mise à jour, promotion ou événement — et
vous perdez alors votre progression pour rien.

Le blocage est le juste milieu : le jeu reste installé, votre progression est préservée, mais il ne s'ouvre
pas quand vous avez décidé qu'il ne le devait pas.

## Option 1 : la minuterie de Bien-être numérique (intégrée)

Sur la plupart des téléphones Android : **Paramètres → Bien-être numérique et contrôle parental → Tableau
de bord**, choisissez un jeu et fixez une **minuterie**. Une fois le temps écoulé, le jeu est mis en pause
jusqu'à minuit.

- **Idéal pour :** un léger plafond quotidien sur un ou deux jeux.
- **Limites :** un jeu à la fois, pas de planning hebdomadaire, et la minuterie se désactive facilement
  dans les paramètres quand vous voulez « encore une partie ».

## Option 2 : Google Family Link (pour le téléphone d'un enfant)

**Family Link** permet à un parent de gérer le téléphone Android d'un enfant depuis le sien : limites
quotidiennes, blocage de certaines applications, heure du coucher et approbation des nouveaux
téléchargements.

- **Idéal pour :** les parents de jeunes enfants.
- **Limites :** il est conçu pour gérer le téléphone de quelqu'un d'autre, pas le vôtre, et nécessite un
  compte Google supervisé.

## Option 3 : un bloqueur d'applications avec plannings et minuteur

Un bloqueur d'applications vous permet de bloquer tous vos jeux d'un coup, selon vos conditions. Avec
[Mindful Guard](/fr/apps/mindful-guard) :

1. Installez Mindful Guard et autorisez le **service d'accessibilité** lorsqu'il vous le demande. Il s'en
   sert pour repérer l'ouverture d'une application bloquée.
2. Ajoutez vos jeux à une **liste de blocage**.
3. Choisissez comment les bloquer :
   - avec un **planning hebdomadaire**, par exemple en semaine de 9 h à 17 h et chaque nuit après 23 h, ou
   - avec un **minuteur de concentration** rapide de 5 à 60 minutes pour une séance de travail ou de
     révision.
4. C'est tout. Tant que le blocage dure, les jeux ne s'ouvrent pas et il n'y a aucun bouton de
   contournement.

## Quelle option choisir

| Vous voulez… | Meilleure option |
|---|---|
| Plafonner un jeu un peu chaque jour | Minuterie de Bien-être numérique |
| Gérer le téléphone d'un enfant | Google Family Link |
| Bloquer tous les jeux pendant le travail, les révisions ou la nuit | Bloqueur avec planning hebdomadaire |
| Bloquer les jeux le temps d'une session de concentration | Minuteur d'un bloqueur d'applications |

## Pour que le blocage tienne

- **Bloquez des heures, pas le jeu pour toujours.** Gardez un créneau pour jouer, par exemple le week-end
  après-midi. Une interdiction appelle les contournements ; un plan, non.
- **Désactivez les notifications des jeux.** Les événements et les alertes « votre énergie est pleine »
  sont le déclencheur de l'habitude.
- **Bloquez aussi l'heure avant le coucher.** Les parties tardives coûtent du sommeil, pas seulement du
  temps.
- **Attention au transfert.** Si vous arrêtez de jouer pour scroller, limitez aussi les fils :
  [limiter les Reels par jour](/fr/blog/limit-reels-per-day-android).

## En résumé

Bien-être numérique suffit pour un plafond léger, et Family Link est le bon outil pour le téléphone d'un
enfant. Pour garder vos propres jeux fermés aux heures qui comptent, bloquez-les selon un planning ou
pendant une session de concentration avec un bloqueur sans bouton de contournement.
