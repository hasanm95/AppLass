**Android limite le temps d'écran par application, pas pour tout le téléphone.** Utilisez les minuteurs de
Bien-être numérique pour plafonner chaque jour les applications qui vous prennent le plus de temps, le mode
Coucher pour garder vos soirées libres, et Google Family Link s'il s'agit du téléphone d'un enfant. Si vous
avez besoin d'une limite impossible à désactiver dans un moment de faiblesse, utilisez un bloqueur
d'applications sans bouton de contournement.

## Pourquoi limiter application par application

Le temps d'écran total comprend aussi les cartes, les messages, les appels et le travail. Ce que la plupart
des gens veulent réduire, ce sont les quelques applications qui transforment cinq minutes en cinquante :
réseaux sociaux, vidéos courtes et jeux. Les estimations de l'usage quotidien moyen du smartphone tournent
autour de quatre à cinq heures selon les études
([Exploding Topics](https://explodingtopics.com/blog/smartphone-usage-stats)) — et la part qu'on regrette se
concentre dans quelques applications. Voilà pourquoi des limites par application fonctionnent mieux qu'un
grand chiffre global.

## Option 1 : les minuteurs de Bien-être numérique (intégrés)

Sur la plupart des téléphones Android :

1. Ouvrez **Paramètres → Bien-être numérique et contrôle parental**.
2. Touchez le **tableau de bord** (ou la liste des applications sous le graphique d'utilisation).
3. Choisissez une application et touchez le **minuteur** (le sablier).
4. Choisissez une limite quotidienne, par exemple 30 minutes.

Une fois le temps écoulé, l'icône passe en gris et l'application est en pause jusqu'à minuit
([guide Android de Google](https://guidebooks.google.com/android/exploremorefeatures/settimersforyourapps)).

**Sur Samsung :** Paramètres → **Bien-être numérique et contrôle parental**, touchez une application sous le
graphique, puis **Minuteur de l'application**.

**Limites :** une application à la fois, pas de planning hebdomadaire, et le minuteur s'augmente ou se
supprime dans les paramètres dès que vous voulez « juste un peu plus ».

## Option 2 : le mode Coucher et le mode Concentration

- Le **mode Coucher** (Bien-être numérique → mode Coucher) passe l'écran en noir et blanc et coupe les
  notifications selon un horaire que vous choisissez. Il limite *quand* vous utilisez le téléphone, pas
  *combien de temps*.
- Le **mode Concentration** (Bien-être numérique → mode Concentration) met en pause les applications
  choisies tant qu'il est actif. Pratique pour une séance de travail — mais avec **Faire une pause**, les
  applications reviennent aussitôt.

Les noms de menu peuvent varier selon la marque et la version d'Android.

## Option 3 : Google Family Link (pour le téléphone d'un enfant)

**Family Link** permet à un parent de gérer le téléphone Android d'un enfant depuis le sien : une **limite
quotidienne** pour tout l'appareil, des limites par application, une heure du coucher et l'approbation des
nouveaux téléchargements. L'enfant ne peut pas modifier ces limites sur son téléphone. Il faut un compte
Google supervisé, et l'outil est conçu pour les parents, pas pour limiter son propre téléphone.

## Option 4 : un bloqueur d'applications pour des limites impossibles à désactiver

Sur votre propre téléphone, tous les outils intégrés ont le même point faible : la limite n'est qu'à quelques
pressions d'être levée. Un bloqueur d'applications comble ce manque. Avec
[Mindful Guard](/fr/apps/mindful-guard) :

1. Installez Mindful Guard et autorisez le **service d'accessibilité** lorsqu'il vous le demande. Il s'en sert
   pour repérer l'ouverture d'une application ou d'un fil bloqué.
2. Choisissez comment limiter :
   - **Reel Guard** : une limite quotidienne et par session pour le fil Reels, Shorts, TikTok, Reels de
     Facebook ou Snapchat Spotlight, pendant que le reste de l'application fonctionne ;
   - un **planning hebdomadaire** qui bloque des applications pendant le travail, les révisions ou la nuit ;
   - un **minuteur de concentration** de 5 à 60 minutes.
3. Une fois la limite atteinte, un écran calme prend le relais, sans bouton de contournement.

## Quelle option choisir

| Vous voulez… | Meilleure option |
|---|---|
| Plafonner un peu une ou deux applications par jour | Minuteur de Bien-être numérique |
| Garder le téléphone calme la nuit | Mode Coucher |
| Bloquer les distractions le temps d'une séance | Mode Concentration ou minuteur d'un bloqueur |
| Limiter tout le téléphone d'un enfant | Google Family Link |
| Limiter seulement le fil Reels ou Shorts | Bloqueur avec limites au niveau du fil |
| Une limite impossible à lever dans un moment de faiblesse | Bloqueur sans bouton de contournement |

## Des limites de départ qui tiennent

- **Choisissez vos trois applications principales**, pas tout. Regardez le tableau de bord et plafonnez les
  trois où vous passez le plus de temps.
- **Utilisez une limite par session pour les fils.** Une limite quotidienne seule s'épuise en un long
  scroll ; voir [la méthode des sessions pour limiter les Reels](/fr/blog/limit-reels-per-day-android).
- **Gardez la dernière heure avant le coucher** sans réseaux sociaux, avec le mode Coucher ou un planning.
- **Faites le point au bout d'une semaine** et resserrez ce qui était facile.

Pour aller plus loin sur les outils intégrés, voir
[Bien-être numérique ou applications de concentration tierces](/fr/blog/android-digital-wellbeing-vs-third-party-focus-apps).

## En résumé

Bien-être numérique couvre l'essentiel : minuteurs par application, mode Coucher pour la nuit et Family Link
pour les enfants. Sa faiblesse : sur votre propre téléphone, une limite se lève facilement. Si c'est
précisément le problème, un bloqueur sans bouton de contournement en fait une limite qui tient.
