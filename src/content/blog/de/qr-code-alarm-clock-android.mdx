**Ein QR-Code-Wecker hört erst auf, wenn Sie einen Code scannen, den Sie woanders hingelegt haben.** Vom
Bett aus können Sie ihn nicht stummschalten. Sie müssen aufstehen, zum Code gehen und die Kamera darauf
richten. Wenn er verstummt, stehen Sie und sind wach genug, um nicht zurück unter die Decke zu kriechen.

## Warum der Aus-Knopf das Problem ist

Die meisten, die Wecker verschlafen, verschlafen gar nicht den Ton. Sie schalten ihn aus, ohne richtig
wach zu werden, und erinnern sich nicht daran. Ein Aus-Knopf mit einem Tipp oder eine Schlummertaste ist
im Halbschlaf leicht zu treffen.

Das Telefon ans andere Ende des Raums zu legen, hilft eine Weile — bis Sie lernen, hinzugehen, es
auszuschalten und zurück ins Bett zu gehen. Ein Barcode-Wecker geht einen Schritt weiter: Das Telefon kann
neben dem Bett bleiben, aber der **Code** liegt woanders, und nur der Code schaltet den Wecker aus.

## So funktioniert ein Barcode-Wecker

1. Beim Stellen des Weckers wählen Sie den Code, den er akzeptiert: einen QR-Code oder einen Barcode auf
   einem Gegenstand, den Sie besitzen.
2. Am Morgen klingelt der Wecker und hört nicht auf.
3. Um ihn zu stoppen, gehen Sie zum Code und scannen ihn mit der Kamera des Telefons.
4. Ein anderer Code oder gar keiner — und er klingelt weiter.

Zwei Dinge wecken Sie dabei auf. **Bewegung** bringt Ihren Körper in die Senkrechte und den Kreislauf in
Schwung. **Die Kamera auszurichten** braucht gerade so viel Konzentration, dass es nicht im Halbschlaf geht.

## Wo der Code hingehört

Wählen Sie einen Platz, der ein paar Schritte entfernt ist und in Ihren Morgen überleitet:

| Platz | Warum es wirkt |
|---|---|
| Waschbecken | Sie sind schon dort, wo Sie Zähne putzen |
| Kaffeemaschine oder Wasserkocher | Scannen, dann den Kaffee starten |
| Küchenarbeitsplatte | In den meisten Wohnungen am weitesten vom Bett entfernt |
| Haustür | Gut für frühe Läufe oder Pendelwege |

Nutzen Sie einen Gegenstand, der **nicht wandert**: eine Shampooflasche, eine Kaffeepackung, einen
Aufkleber an einer Schranktür. Ist der Code am Morgen nicht da, hört der Wecker nicht auf — legen Sie ihn
also dorthin, wo er nicht verschwinden kann. Und sorgen Sie für etwas Licht am Platz oder schalten Sie
unterwegs eines ein: Das hilft auch beim Wachwerden.

## Einen Barcode-Wecker mit Arisely einrichten

[Arisely](/de/blog/arisely-alarm-clock-for-heavy-sleepers) ist ein Android-Wecker für Tiefschläfer. Er
klingelt in voller Lautstärke, bis Sie die gewählte Aufwach-Aufgabe erledigt haben, die Arisely **Ritual**
nennt. QR / Barcode ist eines dieser Rituale:

1. Installieren Sie Arisely und erstellen Sie einen neuen Wecker.
2. Tippen Sie auf **Ritual**, wählen Sie **QR / Barcode** und dann eine Schwierigkeit.
3. Folgen Sie den Schritten auf dem Bildschirm, um den Code einzurichten, den Sie scannen werden.
4. Legen Sie den Gegenstand dorthin, wohin Sie morgens gehen wollen.
5. Testen Sie den Wecker einmal am Abend, damit Sie wissen, dass der Code sich scannen lässt.

Arisely klingelt über den Wecker-Audiokanal von Android und ist daher laut, selbst wenn die
Medienlautstärke heruntergedreht ist. Die Kamera liest nur den Code: Die Bilder werden auf Ihrem Telefon
verarbeitet und nie aufgezeichnet, gespeichert oder übertragen.

## Damit es hält

- **Keinen Ersatzcode neben dem Bett.** Ein Foto des Codes auf einem anderen Bildschirm macht den Sinn
  zunichte.
- **An schweren Tagen andere Rituale nutzen.** Reicht ein Scan nicht, lassen sich für andere Wecker
  Rituale wie Schritte, Rechnen oder von der Kamera gezählte Liegestütze nutzen. Siehe
  [Wecker mit Aufgaben](/de/blog/alarm-clock-with-missions-to-turn-off).
- **Auch die Grundlagen klären.** Ein Barcode-Wecker hilft nicht, wenn der Wecker gar nicht klingelt.
  Stellen Sie sicher, dass Android ihn nicht blockiert:
  [Warum Android-Wecker nicht klingeln](/de/blog/why-android-alarms-dont-go-off-exact-alarms).

## Fazit

Wenn Sie Wecker im Schlaf ausschalten, legen Sie den Aus-Schalter außer Reichweite. Ein QR- oder
Barcode-Wecker bringt ihn ans andere Ende des Raums, hinter ein paar Schritte und einen Moment
Konzentration — meist genug, damit Sie aufbleiben.
